## Notas

- El diagrama simplifica "Backend : Autenticacion" como un solo objeto; en el codigo real esa logica esta repartida entre el endpoint ([`auth.py`](/backend/app/api/v1/endpoints/auth.py)), el modulo de seguridad ([`security.py`](/backend/app/core/security.py)) y el modulo de auditoria ([`audit.py`](/backend/app/core/audit.py)).
- No existe un metodo dedicado tipo `GenerarSessionID()` como funcion aislada: es una asignacion de un `uuid4` mas la creacion del JWT ([`create_access_token`](/backend/app/core/security.py#L20)), que van juntos dentro de [`_issue_token`](/backend/app/api/v1/endpoints/auth.py#L47).
- La validacion de sesion en cada request autenticado (no mostrada en este diagrama, ocurre en cada CU posterior) vive en [`get_current_user()`](/backend/app/api/deps.py#L17).
